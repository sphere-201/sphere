Skills

The client asks. The server decides.

Every system on this page runs on the same rule: the client is never trusted with an outcome. That rule is what keeps a game from getting torn apart by exploiters the week it launches.

  • Luau typed · idiomatic · fast
  • Systems architecture independent, expandable services
  • Client–server development remotes & replication
  • Gameplay programming mechanics that feel right
  • UI programming state-driven interfaces
  • Data & player state sessions · saves · inventories
  • Debugging find it, fix it, explain it
  • Performance optimization frame budget respected

hitRemote.OnServerEvent:Connect(function(player, target)
    if not HitboxService:Validate(player, target) then return end
    DamageService:Apply(target, moves[player].Damage)
end)
